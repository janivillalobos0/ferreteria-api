# API de Facturación - Sistema de Ferretería

API REST desarrollada para la gestión de inventario, control de clientes y emisión de facturas para un negocio de ferretería.

## Tecnologías Sugeridas
- **Backend:** Node.js (Express) / Python (FastAPI) / Spring Boot (Java)
- **Base de Datos:** PostgreSQL o MySQL
- **Autenticación:** JSON Web Tokens (JWT)
